# Akuma Kawaii

Este es mi primer proyecto web. Lo hice porque me gusta mucho el estilo kawaii oscuro y quería practicar lo que estoy aprendiendo de programación.  
La página tiene varias secciones: productos, reseñas y un formulario de contacto.

## Lo que contiene:
- Un inicio con un mensaje de bienvenida y un video de un opening.
- Una parte de productos con imágenes kawaii.
- Reseñas que se ven más gorditas y centradas.
- Un formulario para que la gente pueda dejar un mensaje.
- Un footer con créditos.

## Tecnologías:
Usé HTML y CSS. Aprendí a usar Formspree, Flexbox, Grid y también un poco de Media Queries para que se vea bien en distintos tamaños de pantalla.

## Cómo se usa:
El proyecto está publicado con **GitHub Pages**, así que se puede ver directamente online desde el repositorio.  
Solo hay que entrar al enlace de GitHub Pages y navegar la página.
